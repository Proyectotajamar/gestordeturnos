# 📅 Gestor de Turnos - Operadores

Un sistema web interactivo, dinámico y optimizado para la gestión, visualización y planificación de turnos de operadores. Diseñado con una interfaz desktop-first elegante y moderna que facilita la administración del cronograma de trabajo y las excepciones de personal.

## 🚀 Características Principales

*   **📅 Calendario Semanal Interactivo**: Visualización clara del cronograma de operadores.
*   **🛠️ Gestión de Excepciones**: Modifica turnos fácilmente asignando estados como vacaciones, carpetas médicas, francos compensatorios, devoluciones (DEV) y coberturas.
*   **📊 Importación de CSV**: Importa archivos `.csv` para extraer de forma automática y precisa todas las vacaciones, devoluciones y carpetas médicas cargadas previamente.
*   **⚡ Interfaz Premium y Moderna**: Desarrollado con **Tailwind CSS** y tipografía **Inter** para una experiencia fluida con micro-animaciones y efectos visuales de alta calidad.
*   **🛡️ Configuración Segura**: Estructura limpia y optimizada con control de variables y soporte para despliegues rápidos en plataformas como Vercel.

## 🛠️ Tecnologías Utilizadas

*   **HTML5** - Estructura semántica avanzada.
*   **JavaScript (ES6+)** - Lógica dinámica de turnos, rotaciones e importación/procesamiento de datos CSV.
*   **Tailwind CSS** - Estilización y diseño premium responsive.
*   **Google Fonts (Inter)** - Tipografía optimizada para lectura rápida de cronogramas.

## 📂 Estructura del Proyecto

*   `index.html` - La interfaz de usuario principal del gestor de turnos.
*   `app.js` - Lógica central del sistema, que maneja las excepciones, el motor de rotación y las importaciones CSV.
*   `.gitignore` - Configuración para evitar subir archivos locales sensibles o metadatos de despliegue a GitHub.
